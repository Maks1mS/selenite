# Участие в проекте

Мы приветствуем сообщения об ошибках, предложения по улучшению и вклад в код.

## Требования

- [Go](https://go.dev/)
- [Task](https://taskfile.dev/)
- [pre-commit](https://pre-commit.com/)

## Быстрый старт

1. Клонируйте репозиторий.
2. Установите хуки:
   ```bash
   pre-commit install
   ```

## Проверки и тесты

Основные команды `task`, используемые в проекте:

| Команда | Назначение |
|---------|------------|
| `task fmt` | Автоисправление стиля кода |
| `task test-unit` | Модульные тесты |
| `task test-integration` | Интеграционные тесты |
| `task test-e2e` | E2E тесты |
| `task test-golden-update` | Перегенерировать golden-файлы dashboard после намеренного изменения UI |
| `task mocks` | Перегенерировать моки testify через mockery |
| `task license-headers-fix` | Добавить заголовки лицензии MPL-2.0 |
| `task license-check` | Проверить лицензии зависимостей |

Остальные команды можно посмотреть вызвав:

```shell
task
```

## Разработка

Для быстрого отладочного запуска можно поднять локальную VM:

```bash
task dev:start-vm dev:provision
task dev:ssh -- machine info
```

## Использование ИИ

ИИ-инструменты можно использовать для помощи в написании кода, но вы
несёте ответственность за результат:

- Не отправляйте код, который вы не понимаете полностью.
- Issues и сообщения в PR пишите сами. Использовать ИИ для проверки
  орфографии или грамматики (без значительных изменений) — нормально,
  но не генерируйте целые сообщения c помощью ИИ.
